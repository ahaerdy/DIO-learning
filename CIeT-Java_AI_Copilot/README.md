Este repositório reúne os exercícios, projetos e anotações desenvolvidos por mim durante o Bootcamp **CI&T: Java AI Copilot**, oferecido pela plataforma DIO em parceria com a CI&T.

O conteúdo abrange desde os fundamentos de Inteligência Artificial aplicados ao dia a dia do desenvolvedor, passando pelos fundamentos da linguagem Java e programação orientada a objetos, até o uso do GitHub Copilot como copiloto de codificação e a construção de APIs REST modernas com o ecossistema Spring (Boot, Data, Security, Cloud).

## Tecnologias e Tópicos Abordados

Durante o Bootcamp, os principais conhecimentos praticados são:

- Inteligência Artificial aplicada ao desenvolvimento: Machine Learning, LLMs, IA Generativa e Agentes
- Engenharia de Prompts e uso de agentes de estudo (DIO Agent)
- Fundamentos da linguagem Java e ambiente de desenvolvimento
- Estruturas de controle e sintaxe da linguagem Java
- Programação Orientada a Objetos (abstração, encapsulamento, herança, polimorfismo)
- Interfaces, Lambdas, Collections e tratamento de exceções em Java
- GitHub Copilot: configuração do ambiente, Copilot Chat e Copilot CLI
- Engenharia de Prompts aplicada ao GitHub Copilot
- Fundamentos da Web e do protocolo HTTP
- Anotações em Java e geração de código inteligente
- Boas práticas: Clean Code e princípios SOLID
- Design Patterns clássicos (GoF) aplicados com Spring Framework
- APIs REST com Spring Boot e Spring Web
- Persistência de dados com Spring Data
- Segurança em APIs com Spring Security
- Integração com APIs externas usando Spring Cloud OpenFeign
- Reconhecimento de fala aplicado a soluções back-end inteligentes
