#  Materiais de Apoio

## Conheça o DIO Agent

O DIO Agent é um agente de inteligência artificial de código aberto, criado para te acompanhar em qualquer experiência educacional da DIO. Ele não só responde perguntas: ele age, lê os arquivos do seu curso e usa habilidades específicas para te ajudar a aprender de verdade, em vez de simplesmente entregar respostas prontas.

📦 [Acesse o Repositório Oficial do DIO Agent](https://github.com/digitalinnovationone/dio-agent)

Lá está tudo: código-fonte, a persona do agente e as skills disponíveis, sempre atualizado. Vale deixar essa aba aberta, você vai usar esse link já no próximo passo.

## O Que Vem por Aí

Este é o roteiro dos próximos passos:

* **Passo 1: Instale um Harness!** Você instala o Google Antigravity, o programa que dá vida ao agente na sua máquina. Também mostramos alternativas como Claude Code, Cursor, OpenCode e Gemini CLI, caso prefira outra opção.
* **Passo 2: Configure o DIO Agent!** Você baixa o repositório oficial (o mesmo que acessou acima) e deixa o agente pronto para uso, seja via clone, download do zip ou pedindo para o próprio harness fazer isso por você.
* **Passo 3: Hands On!** Em quatro vídeos, você coloca a mão na massa e testa na prática as três skills do agente: Plano de Estudos, Destravar Desafio (em desafios de projeto e de código) e Explicar Conceito.

*Obrigado a quem trouxe feedback sobre o áudio dos vídeos: já estamos ajustamos por aqui, inclusive algumas melhorias já foram aplicadas. Seguimos sempre atentos para melhorar e atualizar o conteúdo sempre que for preciso e o próprio DIO Agent tem novidades a caminho em breve, já que muita gente da comunidade está colaborando com o projeto, que é open source.*
