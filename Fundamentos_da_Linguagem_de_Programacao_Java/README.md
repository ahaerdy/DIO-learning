Este repositório reúne os exercícios, projetos e anotações desenvolvidos por mim durante a [Formação Java Fundamentals](https://web.dio.me/track/formacao-java-fundamentals), oferecida pela plataforma DIO.

O conteúdo abrange uma experiência prática com os conceitos essenciais da linguagem Java, cobrindo desde a sintaxe e o ambiente de desenvolvimento até programação orientada a objetos, estruturas de dados, gerenciamento de exceções, manipulação de arquivos com I/O, gerenciamento de dependências com Maven e Gradle, boas práticas de código com SOLID e Clean Code, e persistência de dados com JDBC.

## Conteúdo do Repositório

Cada diretório contém:
- Exercícios resolvidos relacionados aos fundamentos da linguagem Java
- Notas e explicações sobre conceitos de sintaxe, POO, exceções, I/O e persistência
- Projetos práticos desenvolvidos ao longo da formação
- Experimentos de código para validação de ideias e testes de implementação
- Recursos de estudo complementares utilizados durante a formação

---

## Tecnologias e Tópicos Abordados

Durante a Formação, os principais conhecimentos praticados são:

- Sintaxe da linguagem Java e ambiente de desenvolvimento
- Estruturas de controle (condicionais e laços de repetição)
- Programação Orientada a Objetos: abstração, encapsulamento, herança e polimorfismo
- Interfaces, expressões Lambda e Streams
- Collections e outras classes utilitárias do Java
- Debugging e tratamento de exceções
- Manipulação de arquivos e diretórios (I/O)
- Gerenciamento de dependências com Maven e Gradle
- Annotations em Java
- Boas práticas: princípios SOLID e Clean Code
- Persistência de dados com JDBC
