Este repositório reúne os exercícios, projetos e anotações desenvolvidos por mim durante o [Bootcamp Itaú: Java com Inteligência Artificial](https://web.dio.me/track/itau-java-com-inteligencia-artificial), oferecido pela plataforma DIO em parceria com o Itaú.

O conteúdo abrange desde os fundamentos modernos de Inteligência Artificial e sua aplicação no dia a dia do desenvolvedor, passando pelos fundamentos da linguagem Java, programação orientada a objetos, boas práticas de desenvolvimento web, até a construção de APIs REST modernas com o ecossistema Spring (Boot, Data, Security, Cloud) integradas a soluções de IA generativa.

## Tecnologias e Tópicos Abordados

Durante o Bootcamp, os principais conhecimentos praticados são:

- Inteligência Artificial aplicada ao desenvolvimento: Machine Learning, LLMs, IA Generativa e Agentes
- Engenharia de Prompts e uso de agentes de estudo (DIO Agent)
- Fundamentos da linguagem Java e ambiente de desenvolvimento
- Estruturas de controle e sintaxe da linguagem Java
- Programação Orientada a Objetos (abstração, encapsulamento, herança, polimorfismo)
- Interfaces, Lambdas e Collections em Java
- Debugging e tratamento de exceções
- Fundamentos da Web e do protocolo HTTP
- Anotações em Java e geração de código inteligente
- Boas práticas: Clean Code e princípios SOLID
- Design Patterns clássicos (GoF) aplicados com Spring Framework
- APIs REST com Spring Boot e Spring Web
- Persistência de dados com Spring Data JPA
- Segurança em APIs com Spring Security
- Integração com APIs externas usando Spring Cloud OpenFeign
- Spring AI e reconhecimento de fala aplicados a soluções back-end
